Sprint "Secrets - New Module" (ADR 0141, COM-1563). Builds on COM-1576. It follows GCP discovery (ADR 0104). Steve's estate is mostly AWS and Azure, so this comes after GitHub.

## What people see

- **Secret Manager on Discovered.** Each secret shows:
  - project and name, and its labels;
  - created;
  - its newest version's created date (= **last changed**);
  - **expires**, if set;
  - its rotation schedule, if set.

  It has the same choices as other stores. A Google-set expiry carries through to Next due, as Key Vault's does.
- **Labels.** Google labels allow lower case only, so the Kept in card offers `compass-secret` = `sec-12` and `compass-source-key` = the key's ID in lower case, and matching ignores case.
- **Service account keys as sources.** Generated by ▸ Google service account key. Each key shows:
  - the service account;
  - the key ID;
  - created, and **expires**;
  - enabled or disabled.

  Only keys that people created are listed; Google-managed keys are left out. A key with no real expiry (Google's year-9999 default) is **Long-lived**.
- **Rotation proven** when:
  1. a new key appears on the same service account;
  2. every stored copy is updated;
  3. the old key is disabled or deleted.

  Recorded as **Seen at source and store**.

## Notes (technical)

- Permissions on the Compass role: `secretmanager.secrets.list`, `secretmanager.versions.list` and `iam.serviceAccountKeys.list`. **Test that `secretmanager.versions.access` is never in the role.** Use Secret Manager Viewer's metadata permissions, not the Accessor role.

- Store entries are kind `gcp_secret_manager`.
