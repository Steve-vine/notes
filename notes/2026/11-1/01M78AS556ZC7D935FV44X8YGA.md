Found in the sprint 116 round-3 pre-UAT pass on staging (3175d2ad, 2026-11-12), next to COM-1761. Not caused by round 3.

**What happens** (in a record's history and in Admin ▸ Activity):
- Technology assets read "created / updated / deleted **container** AST-xx".
- Installed software reads "created container software <uuid>".
- A data asset's location reads "created data asset container <uuid>".
- SAP control links show Entity "sap_control_links" and read "created SAP control link Plan link to a control", naming neither the entry nor the control.
- Updates show "Status changed at: …" (an internal field name).
- The Entity filter lists "Data subject request deadline rule" twice.

**What it should do:** every row names things in screen words with their references, e.g. "created technology asset AST-38", "installed SFT-25 on AST-42", "AST-42 holds DAT-12", "linked control ACC.1 to SAP-72"; internal field names don't show; the Entity filter has no duplicates.

**Done when:** these entity types read in screen words in the history and in Admin ▸ Activity (new rows; say whether old rows change), the filter has no duplicate entries, and tests cover each. Backend wording, independent.
