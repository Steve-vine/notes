On the Assessment screen, the **Playbook ↗** link at the top right of an open control takes you to that control's Playbook page. There's no way back the other way. Steve (2026-11-07): add a **Posture** link in exactly the same place on the control page that opens the control in the Assessment view, so you can switch quickly between the two.

**Wanted behaviour:**
- The control page (Playbook ▸ Controls ▸ a control) shows **Posture ↗** at the top right of its header, styled like the Assessment screen's Playbook link: the same subtle button with the same arrow icon, in the same position.
- It opens Posture ▸ Assessments with that control open, for the company currently selected.
- Like the Playbook link, it's a real link, so it can open in a new tab.
- It's only shown to someone who can see Assessments, and only when a company is selected.
- A control that isn't in the assessment list (disabled) shows no link.
- Edit and the control's menu stay where they are, next to it.

**Done when:** in E2E Test Company, from a control page Posture opens that control on the Assessment screen; its Playbook link goes back; a user without Assessments sees no Posture link.

**Implementation:** `DetailHeader` actions in `ControlDetailPage.tsx` (~line 226): add a `Button component={Link} to={/assessments/${control.ref}}` with `ArrowUpRightIcon`, matching the Playbook button in `ControlFocus`. Today the actions only render for `canWriteLibrary`, so restructure so the Posture link shows for readers too. Gate on the same section check the `/assessments` route uses (`RequireSection` in App.tsx ~line 545) and on `control.status === 'active'`.

**Independent:** no migration, no API change.
