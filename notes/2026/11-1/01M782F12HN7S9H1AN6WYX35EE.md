Found in the sprint 116 round-2 pre-UAT pass on staging (2026-11-12).

**What happens:** creating a plan entry (SAP-71 in E2E Test Company) writes a history row reading "created sap entry **SAP-None** · …". The entry's reference isn't known yet when the row's words are written.

**What it should do:** the row reads "created SAP entry SAP-71 · …". Rows already written with "SAP-None" are put right where the entry can be identified.

**Done when:** a new plan entry's Created row, in its history and in Admin ▸ Activity, shows its real reference; existing "SAP-None" rows on staging read their entry's reference after the deploy; and any other record type that names itself the same way at creation is checked for the same fault.
