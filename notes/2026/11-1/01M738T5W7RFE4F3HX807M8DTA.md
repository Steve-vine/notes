**Why.** Steve's requirement (2026-11-10) is that completing the SOC 2 controls in Compass says categorically that SOC 2 is met, without any unnecessary control having been done. Today it doesn't, for two reasons:
- **Too many controls.** SOC 2 has 528 links to 265 controls; before COM-1669 it had 130. Compass counts a criterion met only when *every* linked control is implemented. So the "related" links added in COM-1669 make people do work the criterion doesn't need.
- **Not enough cover.** 18 criteria rest on a single control that only does part of the job (`audit/soc2-mapping.md`).

**The three rules** (Steve's words, condensed):
1. **Enough.** If every linked control is met, there's no doubt the criterion is met.
2. **Nothing extra.** No control is linked that the criterion doesn't need.
3. **No either/or.** Each criterion has one set of controls, never "this set or that set".

So across SOC 2 the linked controls form one set. Completing it means SOC 2 is met, and nothing in it is unneeded.

**What this decides** (a new ADR amending 0056, for SOC 2):
- **The bar is the points of focus.** "No doubt" is judged against every AICPA point of focus (2017 TSC, revised 2022), not the criterion's one-line title. A point that can't apply to any organisation using Compass is written down as such, with the reason.
- **Each point of focus is carried by exactly one control.** A control stays linked only if it carries a point that no other linked control in that criterion carries.
- **Shape of a criterion's links.** It has one of two shapes, never both on the same criterion:
  - one control that does the whole job (`equal`/`superset_of`) and nothing else; or
  - a set of partial controls (`subset_of`/`intersects_with`) declared complete together.
- **The smallest set across the framework.** When two controls could carry a point, prefer the one SOC 2 already needs elsewhere.
- **Broad controls are fine.** A control broader than SOC 2 needs is acceptable; controls aren't split for one framework.
- **Not applicable stays as it is.** A control a company marks not applicable still drops out of that company's figure. That's a recorded decision, for example a carved-out data centre.
- **Other frameworks are unchanged.** Whether the same rules apply to them is decided in their own reviews (COM-1671, COM-1673..1680).
