Prove the whole path with Copilot and fix whatever is specific to it.

**Wanted behaviour:** an administrator builds one area agent (start with Access Control, the largest at 102 tools) in Copilot Studio by following the Connect page's guide, and publishes it. A person opens it in Teams or Microsoft 365 Copilot, signs in to Compass in the browser, allows it, and can use that area's tools. Changes show in Activity as theirs via Polaris.

**Done when:** on staging, in E2E Test Company:
- An area agent connects and lists that area's tools; check whether Copilot accepts all of them.
- It runs a read tool and a write tool, and the write shows in Activity via Polaris.
- A second, smaller area agent (e.g. Secrets) connects too.

Pre-UAT first runs a stand-in with Copilot's quirks through the public address. The real Copilot needs the Moneypenny tenant (M365 Copilot licences, and Copilot Studio / Power Platform admin rights), so it is probably marked **Couldn't check** with the exact clicks for Steve.

**Implementation:** fixes land in the open tasks, or as a PR on this one. If Copilot refuses or trims an area's tools, raise it with Steve with options; don't cut tools.

**Independent**, unless a fix needs an API change. After the ADR, area addresses, sign-in and Connect page tasks.
