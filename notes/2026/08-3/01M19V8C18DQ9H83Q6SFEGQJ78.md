COM-543 catches the exits inside the Assessments queue — another row, Next, Previous, close. It cannot catch leaving the page: click Controls in the left nav, or hit browser Back, or edit the same assessment on a control's own detail page and navigate off it, and the typed work still disappears without a word. This task closes the remaining route-level hole, for the assessment panel and for any other screen that holds unsaved edits.

**Expected** — the same prompt, from the same conditions, whichever way you leave: **Save and continue**, **Discard changes**, **Keep editing**. Browser Back that is cancelled leaves you where you were with the address bar unchanged.

**The constraint** — react-router only offers `useBlocker` under a data router, and `main.tsx` mounts a plain `<BrowserRouter>` around `App`'s ~80 routes. So this task is really two: convert the router, then hang the guard off it.

**Implementation**
1. Convert `main.tsx` to `createBrowserRouter` + `RouterProvider`. The route tree in `App.tsx` moves to a route-object array (or stays JSX via `createRoutesFromElements`, which is the smaller diff). Keep the provider nesting as it is — `RootErrorBoundary` stays outside the router (COM-467's last-resort catch), and each shell keeps its own route boundary; don't swap either for the router's `errorElement` in this task.
2. Five test files mount `BrowserRouter`/`MemoryRouter` directly — they keep working with `MemoryRouter`, but check any that assert on navigation.
3. Add a small "unsaved changes" hook wrapping `useBlocker` + `beforeunload`, and have the assessment panel register its dirty flag with it. Reuse whatever confirm dialog COM-543 lands rather than a second one that words it differently.
4. Sweep for other screens that hold unsaved edits and should register too — the vendor form builder and the report wizard are the likely ones; adopt them only where the loss is real.

**Sequencing** — do it after COM-543, which settles the wording and the save-then-continue behaviour. If the router conversion turns out to be a bigger diff than it looks, split step 1 into its own PR and land the guard behind it.
