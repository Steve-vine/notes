Part of sprint 67, Inventory discovery - Software (ADR 0114 §7). Fix-forward for COM-961. Found by Steve on staging, 2026-10-18.

## Why

Steve put the AWS server bstr-staging under the technology asset bstr-staging, saw Ubuntu 24.04 in Discovered ▸ Software and added it to the Software register. The Ubuntu entry shows it is on bstr-staging, "Found by discovery". But the bstr-staging technology asset's **Installed software** card still says "No software recorded on this technology asset". The link shows from the software's side only. COM-961 made the Software tab count typed and discovered installs, but the asset page still lists typed installations only.

## What people see

- **The asset's Installed software card lists both kinds,** in one table:
  - **Typed** installations exactly as today, with ref, publisher, support pill and licences, editable and removable.
  - **Software found by discovery that is in the Software register**: ref, name, publisher and support pill as for typed rows, plus the exact version and the resource it was found on (e.g. "24.04 · bstr-staging"), marked **"Found by discovery"**.
    - These can't be edited or removed here, because the next read would bring them back. The row's help text says how to remove one: take the resource off the asset, or delete the register entry.
    - Recording licences means typing the installation as well. The row then reads **"Typed, and found by discovery"**, as the Software assets tab already does, so it's never listed twice.
- **Software discovery found that isn't in the register yet:** a line under the table reads e.g. "679 more found by discovery and not in the Software register" and links to Discovered ▸ Software showing only this asset's software. Discarded software isn't counted.
- **An asset with nothing beneath it, or nothing found,** reads as today.
- **The same applies in the Inventory portal** where the card appears there, read-only for found rows.
