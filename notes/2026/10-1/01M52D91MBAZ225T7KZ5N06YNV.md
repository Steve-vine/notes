Sprint 72, MCP - Access Control. Scoped with Steve on 2026-10-16. This record is the first task, and the rest wait for it.

Sprint 70 (ADR 0109) connected an AI assistant to Overview, Playbook and Posture, and left the Modules out on purpose. This sprint brings in the first module, **Access Control**, with the same rules: the assistant acts as the person, does exactly what their role allows on screen, and every change is marked "via assistant".

## What Steve decided (2026-10-16)

- **Every Access tab is in scope:** Role matrix, Requests, Validation, Recertification, Coverage, Reports, Access Graph, Users, Groups, Shared Mailboxes, Devices, Directory Roles, Conditional Access, and Access ▸ Admin.
- **Approvals are the same as on screen.** If your role can approve or validate a request, retry a failed one, or approve a recertification removal, the assistant can too. That includes a leaver that deletes the account. These are the steps that change real accounts in Entra, Exchange and Active Directory, so the assistant flags them as destructive and a client that asks before acting asks first. The second-person rule doesn't change: the assistant is you, so it can't approve or validate a request you raised.
- **Access ▸ Admin is read and write**, for people whose role can change it on screen.

## What the record has to settle (Claude's calls, not confirmed by Steve)

- **No new grant.** *Connect an AI assistant* still lets a person connect. From there, the person's Access permissions decide which Access tools they get, as they decide which tabs they see.
- **A joiner's one-time passwords are never given to the assistant.** The screen shows them to the requester or an admin. A conversation with an assistant is kept in a chat history outside Compass, so the passwords stay on screen.
- **Owners' recertification sign-off stays in the Compass Portal.** Portals are still out of scope. The assistant runs recertification from the Access side: schedules, progress, and approving removals.
- **The old campaign-style recertification gets no tools.** It is reached only by an old link. Nor do recertification settings and scopes, which no screen uses any more.
- **No file uploads**, as in ADR 0109. Importing a report definition stays on screen. Exporting one is a download link.
- **The directory is shared and the governance is per company.** Users, groups, mailboxes, devices, directory roles and Conditional Access are one tenant's directory and take no company. Roles, requests, recertification, coverage, reports and Access settings belong to a company, so those tools name it and never guess it.
- **Search reaches Access.** The ⌘K-style search the assistant already has will also find people, groups, business roles and requests.
- **Still out:** the Active Directory connection and directory setup, which are on the main Admin page. So are Vendor Management and Inventory, which have their own sprints.
