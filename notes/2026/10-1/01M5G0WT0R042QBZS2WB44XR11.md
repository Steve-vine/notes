Sprint 82, Evidence (ADR in COM-1198). Builds on COM-1207.

**Chain:** on the chain — migration + API

## What people see

- A search box above the Evidence tabs. Results come in three groups:
  - **Core controls**: number and name;
  - **Framework controls**: framework, number and name;
  - **Evidence**: name, kind, where it came from, status.
- Clicking a core control opens it in By core control; a framework control opens in By framework; a piece of evidence opens its detail.
- **What it matches:**
  - control numbers ("ACC.8", "A.5.18", "CC6.2"), names and guidance;
  - evidence names, descriptions, file names and link titles;
  - near-misses and typos ("firewal review").
- Archived evidence is included only when **Include archived** is ticked.
- It doesn't search the text inside files *(my call; a later sprint if wanted)*.
- The search is kept in the page address, so it can be shared and survives going back.

## Notes (technical)

- Postgres trigram indexes (`pg_trgm`) on the searched columns; one `GET /audit/search?q=` returning the three groups, each capped, with a "show all" per group.
- Respects the same permission filtering as the register.
- URL-backed via the `useQueryState` hooks.

**Done when:** "acc.8", "privileged" and "firewal" each find what they should across the three groups, and a restricted incident's file never appears for someone who can't see it.
