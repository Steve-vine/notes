* **Server-side**: `order_by` + `direction` params on both list endpoints (COM-252/254) — sorting composes with the existing filters and pagination, so page 2 of a sort is real, not a client-side shuffle of the fetched page. Persist the choice alongside the existing persisted filters if that pattern is already wired; don't build persistence just for this.
