The operational face of JML in the new Access section.

* **Raise**: per-kind forms — joiner (batch entry: add rows or paste a list; business role picker per subject), mover (directory-user picker from the mirror, current vs proposed role with a live membership diff preview), leaver (user picker, shows what will be disabled/removed before submission), group create (name/description/owners, optional business-role attachment). For `access_engineer`, the same forms offer **"Submit expedited"** — clearly marked as execute-now-validate-later, never the default, with the incident/justification field required.
* **Approve**: a queue of `pending_approval` standard requests with the full diff of what execution will do; approve/reject with comment; the UI never offers approve to the requester (server enforces, UI shouldn't tease).
* **Validate** *(2026-08-17 amendment)*: a `pending_validation` queue of executed expedited changes (and adopted out-of-band items from COM-244) showing what was **actually provisioned** from the mirror, not just what was requested; validate, or **amend and validate** — the amendment form pre-filled from the current object, executing as a linked corrective request, closing the pair together. SLA countdown / overdue highlighting on the queue; never offered to the original requester.
* **Execute + results**: progress per subject; the joiner **one-time password list** displayed exactly once behind an explicit reveal (copy-all affordance for batches, "this will not be shown again" — mirrors the API's view-once contract); per-subject failures shown with the Graph error and a retry affordance for the failed subset.
* **History**: request list with status pills (`StatusPill`), filterable by kind/status/mode; expedited requests visibly badged; request detail shows the request → approval-or-execution → validation timeline. A small expedited:standard ratio stat on the list header keeps the break-glass path honest.

House patterns: TanStack Query hooks per resource, Mantine forms, toasts via the central `MutationCache`, skeletons + friendly empty states (ADR 0022). Refs: ADR 0045, 0017; `vendors/` feature folder as the structural model.
