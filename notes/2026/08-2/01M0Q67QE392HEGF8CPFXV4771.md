Foundation for read-only device support in Access Control. **Headless by design** — no user-facing surface of its own; the screens land in the dependent tasks. The point: the `$batch` edge crawl already fetches every group's member ids and *drops* the ones that are devices (`tasks/directory_sync.py` — "devices, service principals are dropped"), which is why device-only security groups read as empty.

- [ ] `directory_devices` mirror table, same idiom as `directory_users` (Entra object id `String(64)` PK, `vanished_at` marking never deletion, not audited): display name, `device_id`, OS + version, `account_enabled`, `is_managed`, `is_compliant`, `trust_type`, approximate last sign-in, registration datetime.
- [ ] `directory_group_device_members` edge — the crawl classifies member ids into a third bucket instead of the bin. Current-state fact, reconciled every pass like user memberships.
- [ ] Registered owners edge (`directory_device_owners`, device → mirrored user) — cheapest via `$expand=registeredOwners($select=id)` on the devices crawl; fall back to the `$batch` pattern if `$expand` misbehaves.
- [ ] Full pass: one extra paged `/devices` read (`$top=999`). Delta pass: `/devices/delta` + a stored `devices_delta_link`; membership-only changes already surface the group via the existing groups delta `$expand=members($select=id)`, so the re-crawl mechanism needs nothing new.
- [ ] `DirectorySyncStatus` grows `devices_count` + `devices_delta_link`; the Integrations health card shows the device count alongside users/groups/memberships.
- [ ] **Baseline guard**: the first pass that sees devices must not flood the validation queue — device pairs stay entirely outside out-of-band detection for now (managed-group pair detection remains user-only; the `pre_populated` idiom is the shape if that ever changes).
- [ ] Devices are **browse-only inventory** — outside the governable surface: matrix, JML, recert and unrequested-change detection untouched. Short amendment note to ADR 0045 recording the widened mirror scope.
- [ ] No new consent: `Directory.Read.All` (already granted, `core/graph.py`) covers device reads.

Refs: ADR 0045 §3, COM-237 (mirror), COM-316 (delta), COM-315 ($batch crawl), COM-252 (scope-widening precedent).
