The UX pass on the mirror-based redesign (COM-265/266) — the mappings panel stops asking for raw object ids.

* **Group picker**: replace the free-entry object-id field in `SsoMappingsPanel`'s add-mapping modal with a searchable select over the **directory mirror's groups** (reuse the Access role-matrix picker pattern / directory groups endpoint) — pick "compass-vendor-management" by name; object id + display name captured from the mirror. Keep free-entry as a fallback when the mirror hasn't synced.
* **"Not syncing" state** keys off the mirror (mapped group no longer present in the mirror) instead of `scim_groups`.
* **Prerequisite surfacing**: the SSO Integrations panel and the mappings panel warn when the Entra access connection is unconfigured or the mirror has never synced (SSO's group→role resolution depends on it); link to the Entra access panel.
* **Users section**: provenance column unchanged; the "via *group*" tooltips and affected-user counts now come from the mirror-backed provenance endpoint (no visual change). Remove any lingering SCIM wording ("active/deactivated from SCIM" copy).
* **Tests**: picker feeds from the directory groups endpoint; prerequisite warnings render; mappings CRUD unchanged.

Refs: ADR 0046 amendment, 0022; COM-265, COM-266.
