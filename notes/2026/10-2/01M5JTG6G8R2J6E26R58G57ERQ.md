Sprint 84, DDQ-1 (ADR in COM-1245). Builds on the Sensitive level.

**Chain:** on the chain — migration + API

## What people see

**Admin ▸ Rubrics ▸ Data sensitivity:** each level gains **Can be given in a DDQ**: *Always* · *Only with an NDA in place* · *Never*. It's edited alongside the wording, and each change is kept in the level's revision history (who, when, from → to).

Starting values (COM-1245 call 5): Public Always, Internal Never, Sensitive Only with an NDA, Confidential Never, Restricted Never.

## Notes (technical)

- Enum column on data_sensitivity_levels + revisions (create the type explicitly; see the Alembic enum notes).
- One shared check, used by every later task: `may_share(level_or_none, nda_in_place) -> allowed | held_back(reason)`. None (unclassified) is treated as Internal.
- Rubrics brief updated in the ADR task. Assistant tool that reads the rubric returns the rule.

**Done when:** an admin changes Confidential to "Only with an NDA" and the change is in its history; the check returns held back for an unclassified item.
