## What Steve asked for

Add a link to the trust portal in the Portals section of the left-hand menu. Today that section holds only "User Portal".

## Behaviour

- **A "Trust Centre" entry sits under Portals**, beside User Portal, with the same globe-style icon treatment. Its tooltip reads "The company's public trust centre, as clients see it".
- **It opens the current company's public Trust Centre page in a new tab**, e.g. trust.citops.net/acme. It's the same page clients see, on the trust centre's own address, not inside Compass.
- **It follows the company switcher.** Switch company and the link goes to that company's page.
- **It shows only when there's a page to go to:**
  - the server has a trust centre address;
  - the company has a public short name;
  - its public page is switched on.
  - Otherwise the entry is hidden, so it never leads to a "not found" page.
- **Who sees it:** anyone who can see the Trust Centre module in the menu. The public page is public anyway; the menu entry just follows the module's gate.

## Notes for the build

- The URL is `core/trust_centre_settings.public_page_url(settings)`, i.e. `TRUST_CENTRE_BASE_URL/<public_short_name>`. It's already returned as `public_page_url` by the Trust Centre settings route. Check whether that route is readable by everyone who sees the module, not only managers.
  - If it isn't, add a small read, e.g. `GET /api/v1/trust-centre/public-link`, returning `{url, live}` for the current company. That's an API change, so regenerate schema.d.ts.
- `components/nav.ts`:
  - Add an entry in section `'Portals'`, gated like the Trust Centre module.
  - Nav entries are in-app paths today, so this needs an external-link form: `href`, `target="_blank"`, `rel="noopener noreferrer"`, and an external-link glyph so it reads as leaving Compass.
  - Check `SidebarNav`'s NavLink rendering and the collapsed (icon-only) menu tooltip.
- Hidden while the link query is loading or empty.
- **Tests:**
  - shown with a live page;
  - hidden with no short name, with the page switched off, or with no server address;
  - opens in a new tab with `noopener`;
  - follows a company switch;
  - the nav/sidebar snapshot tests updated.
- Independent unless the new read route is needed.
