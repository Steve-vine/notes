Sprint 90, Integrations (ADR in COM-1347). Builds on COM-1348. This is the frame every tile task fills in.

## What people see

- **Header:** the platform's logo, name and state pill.
- **Overview:**
  - what Compass does with the platform, in plain words;
  - what Compass reads;
  - what it changes, if anything;
  - what has to be granted on the platform's side, with links to the templates Compass already provides (the AWS policy, Azure role, Google Cloud role, AD delegation).
- **Configure:**
  - credentials and settings for the platform as a whole;
  - each company's accounts, where the platform has them. That list follows the company picker, as it does in Inventory today.
  - Secrets stay write-only: saved, never shown again; replace or remove only.
- **Features:** one row per use of the platform, each with:
  - a switch;
  - one line on what it does;
  - what it needs (e.g. "needs the Exchange certificate");
  - for a switch about to go off, a sentence on what stops, e.g. "Compass stops reading these accounts. What it has already found stays in Inventory."
- **Status:**
  - health, with when it was last checked and the platform's own message when it failed;
  - for each account, its last read and any error;
  - a link to System status for the background work.
- **A tile someone can't configure** shows Overview and Status, and Configure and Features read-only.

## Rules

- Switching a feature off keeps its credentials, accounts and everything already read. Switching it back on resumes the schedule.
- A feature whose set-up is missing can't be switched on, and says what's missing.
- Every switch change goes in the activity log.

## Notes (technical)

- The feature-switch store from the ADR, plus a check helper. Beat tasks and on-demand reads call the helper before working, and log a skip at INFO.
- Each integration declares its own Overview text, features and Configure components in the frontend registry. The frame renders them.
- Existing features default to **on**, so nothing stops working on upgrade.

**Chain:** on the chain (migration: feature switches; API).

**Done when:**
- a test tile renders all four tabs;
- a feature switched off is skipped by its scheduled job, and on again it runs at the next slot;
- the switch is in the activity log.
