Sprint 80, Update user portal. Requested by Steve on 2026-10-31. Follows sprint 100's Actions screen (COM-1475).

## What people see

- **Upcoming only** is on by default, as it is internally. It hides anything due beyond the horizon set in Admin ▸ Actions (90 days). Turning it off shows everything.
- **Type chips** sit above the list, the same as internally:
  - All comes first;
  - there is one chip for each Type that has something in it, counted under the current switches;
  - a chip whose count is zero is hidden.
- There is **no My actions switch**: everything on the portal list already belongs to the reader.
- The columns and statuses are those of COM-1475 (Overdue / Due soon / Upcoming / Later), sorted by due date, nearest first.
- The empty state says "Nothing due for you in the next 90 days" and offers to turn off Upcoming only.

This replaces COM-1475's line "without the switches it doesn't need": the portal gets Upcoming only and the chips too.

## Notes (technical)

- `GET /portal/actions` takes the same upcoming filter as the internal `/actions` from COM-1475, using the same code rather than a second copy.
- Switches stay in the address (`useQueryFlag`), so `?upcoming=0` turns it off. Chips use the shared Type labels from COM-1470.
- Screen conventions: put `w="fit-content"` on the switch.
