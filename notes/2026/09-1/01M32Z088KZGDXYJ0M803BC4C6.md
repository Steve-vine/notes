Steve's task - needs access Claude does not have.

1. Make sure the compassitp.com zone is in the Cloudflare account that will host the site.
2. Create a Cloudflare API token for that account that can deploy Workers and manage the zone's routes and DNS (Cloudflare's "Edit Cloudflare Workers" template is the starting point; confirm it covers the custom domain).
3. Add two secrets to the GitHub repo RootCause-IT/compass-website: CLOUDFLARE_API_TOKEN and CLOUDFLARE_ACCOUNT_ID. Running `gh secret set CLOUDFLARE_API_TOKEN --repo RootCause-IT/compass-website` yourself keeps the value out of the Claude session.

Done when: both secrets show in the repo's settings. Nothing deploys until main is pushed.

Technical: the deploy is `wrangler deploy` in .github/workflows/ci.yml, on push to main only. wrangler.jsonc declares compassitp.com as a custom domain, so the first deploy creates the DNS record and certificate itself. (Repo moved to the RootCause-IT organisation on 2026-09-24.)
