A way to actually read the numbers ADR 0064 collects. It's a script to start with. A dashboard can come later if the script turns out not to be enough.

## Agreed work

- [ ] `scripts/checkin-stats.mjs` queries the D1 database via `wrangler d1 execute --remote` and prints:
  - active installs over the last 1 / 7 / 30 days, desktop and headless separately
  - version spread: each install's latest version in the last 30 days, as counts and %
  - os/arch breakdown
  - new installs per day over the last 30 days (ids first seen that day)
  - a daily-active trend, including history that has already been rolled into the aggregate table
- [ ] `--json` flag for piping.
- [ ] Documented in `workers/checkin/README.md`.
