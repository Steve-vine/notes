Website ADR 0002. Mirror ise-website's `deploy.yml` and `preview.yml`.

## Scope

- [ ] `deploy.yml`: on push to `main`, and on `workflow_dispatch` and `repository_dispatch` (the release trigger, ADR 0003), run `npm ci`, lint, format check, `astro check`, build, then `wrangler deploy` via `cloudflare/wrangler-action`. Use a single-flight concurrency group.
- [ ] `preview.yml`: each PR gets a versioned preview URL, posted on the PR.
- [ ] Credentials only from repo secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`.

## Manual step (Steve)

Create a Workers-scoped API token in the Cloudflare dashboard, then set both secrets **from a real terminal**, not through the Claude session. On ISE, the `!`-prefixed `gh secret set` stored an empty value, and a token pasted into the session had to be rolled.

**Done when:** a merge to `main` deploys the site to its workers.dev URL, and a PR gets a working preview link.
