The module joins the rest of Compass (ADR 0072).

* **Permissions**: the Inventory group from the catalogue seeded as real permissions — `inventory.view`, `inventory.manage_register`, `inventory.manage_access`, `inventory.run_recertification`, `inventory.admin` — write implies view; Admin gets all; the roles admin screen lists the group. Migrated roles gain nothing by default except Admin.
* **Navigation**: Inventory in the Modules section beneath Access Control, shown only to holders of `inventory.view`; the AppLayout test that pins the Modules list gains it. Portal nav gains Inventory for `asset_owner` (portal task).
* **Global search** (ADR 0021): containers and data assets as typed results in the selected company — ref, name, aliases, description searchable; deep links to the detail.
* **Dashboard tile**: counts by kind and status, overdue reviews, containers with no owner, containers holding Restricted data with no recertification schedule — the three things an auditor asks first.
* **Activity page**: the new tables render with their entity names and links.
* README / brief note: `brief/information-architecture.md` Modules list updated.

**Acceptance**: a user holding only `inventory.view` sees Inventory in the nav and nothing writable; search finds a container by alias; the tile numbers match the registers.
