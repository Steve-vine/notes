An asset is only useful to governance if the rest of Compass can cite it (ADR 0072). Links between the two registers and the existing entities, visible from either end.

* **Risks** ↔ container / data asset — the `risk_control_link` shape; a risk's detail lists the assets it concerns, an asset's detail lists its risks with score pills.
* **Decisions** ↔ container / data asset — the `decision_link` polymorphic shape gains the two target types; the decision detail's linked-entities section shows them.
* **Vendors**: a container's **supplier** (single vendor FK, for SaaS and third-party-dependent assets, linking to the vendor's risk tier and assessments); a data asset's **third-party recipients** (many vendors, each with an optional DPA reference). The vendor detail gains an **Assets** section listing both.
* **Controls** ↔ container / data asset — Core controls that protect the asset; the control detail lists assets in the selected company.
* Each link is a join table in `_AUDITED_TABLES`; the link editors reuse the existing picker components (the risk↔control picker) rather than a new one.
* Global search wiring for the two registers is in the finishing task, COM-673; this task adds the link surfaces only.

**Acceptance**: link a risk, a decision, a vendor and a control to a container and to a data asset; each appears on the other record; unlinking is audited; a vendor with linked assets shows them.
