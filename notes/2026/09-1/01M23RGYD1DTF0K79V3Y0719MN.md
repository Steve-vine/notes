A line that starts on the day it ships shows nothing useful for months. The revision tables go back to the first assessment, so reconstruct a point per day from them — once — and label every reconstructed day as such.

**What is replayed, and how honestly:**

- **Assessments** — `assessment_revisions` is a full snapshot per change, so for any day D the state of every assessment is its latest revision on or before D. Compliance, tiers, per-domain and maturity fall straight out, computed by feeding that state through the same `core/posture.py` arithmetic (it must accept an in-memory state, not only a live query — refactor as needed, keep the live path identical).
- **Framework posture** — derived from the replayed assessment state through today's mappings and today's exclusions. This is the known inaccuracy, and the reason the row says `reconstructed`.
- **Risks** — `risk_revisions` carry residual scores and status; band and over-appetite against today's rubric.
- **Gaps** — no revision table. A gap is open on day D if `created_at ≤ D` and it was not yet in a done state: use the activity log's field-level entries (COM-629) where they exist, else `updated_at` as the closing date for gaps that are done today. Say so in the docstring.

**Mechanics:**

- `compass backfill-posture [--company slug] [--from YYYY-MM-DD]` in `cli.py`. Idempotent: writes only days with **no row**; never touches an `observed` row, never rewrites a `reconstructed` one. Runs from the earliest revision (or `--from`) to yesterday. Days before a company has any assessment produce no row — the line should not start at zero for a company that did not exist.
- Run it once against staging after the snapshot task deploys, by hand. **Not** in the Helm post-upgrade Job — that job re-runs every deploy and the backfill's job is done once (though re-running is harmless by construction).
- Test on real Postgres: seed three revisions across three dates, run, assert the three days and the values in between; run again, assert nothing changed; insert an observed row, run, assert it survives.
