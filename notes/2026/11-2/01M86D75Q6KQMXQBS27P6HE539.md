Sprint "Vendor Departments" (Steve, 24 Nov 2026). Follows COM-2133.

## Why
Most engagements are created from the user portal, by someone requesting a new vendor or a new engagement for an existing one. Steve: "when creating a new engagement it must be selected from a drop-down list". So the department is chosen there too, and travels with the request to the approver.

## What people see
- **Request a new vendor** and **Request an engagement** (portal, and the admin Requests tab) have the same required **Department** drop-down as COM-2133, listing the active departments of the company the request is for. The same "No departments set up yet" message appears when the company has none, and the request can't be sent.
- **Editing a request** after the approver asks for more information shows and can change the department.
- **Asking for a change to an engagement** (Amend engagement in the portal) can propose a different department. Like the other proposed changes, it only takes effect once the change is approved, and the approver sees it as before → after.
- The **approver's review** of a request shows the department alongside the engagement's other details.
- A request's summary keeps the department name as it was when sent, as it already does for the other fields.
- Polaris's request tools (request a new vendor, request an engagement, request an amendment, edit a request) take and show the department by name, in the same way as COM-2133.

## Done when
- In E2E Test Company, as a portal requester: a new-vendor request and a new-engagement request can't be sent without a department. Sent with one, the approver sees it, and once approved the engagement card shows it.
- An amendment proposing a new department shows before → after to the approver. Approved, the engagement changes. Rejected, it doesn't.
- Editing a request after "more information needed" can change the department.
- A department from another company, or a retired one, is refused on every request route.
- Polaris: `vendors_request_engagement` without a department is refused with a message naming the company's departments.
