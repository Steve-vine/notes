Fix-forward on COM-2120 and COM-2127, found while preparing COM-2157.

**Chain:** independent (documentation only).

**What's wrong:** `docs/runbooks/complete-failure.md` step 0 sets `ARGO_NS=argocd`, but production's Argo CD runs in **`argo-cd`**: every Compass Application in `devops.infrastructure.aws/env/production/config-uk/compass/` says `namespace: argo-cd`. During an incident, the step that saves and switches off Argo's sync would fail, so Argo could start Compass again in the middle of a recovery.

**Done when:** every runbook that names the Argo CD namespace uses `argo-cd` for production. That covers the complete-failure runbook, restore-scheduled-backup.md and the chart README if it says so too. The runbook explains how to check the namespace (`kubectl get applications -A | grep compass`).
