Write the ADR the rest of the Evidence Improvements sprint is built to. Use the next free ADR number when this is built (0163 is the last on main as of 2026-11-20, and the Guided procedures planning has its eye on 0164, so check first).

**Why (Steve, 2026-11-20)**
Steve assessed RIM.9 and uploaded the company's cyber insurance certificate as its evidence. He then set up a recurring schedule entry to assess and renew the insurance, and completed the first one. Marking it done asked for evidence, and the only ways on were to upload the same certificate again or tick No evidence. There was no way to use the evidence already on the control. Today each piece of evidence belongs to one record (a control's assessment, a schedule entry, an incident…). Audits and a finding's closing evidence can already pick from the register, but most places can't. Opening a piece of evidence also shows only its properties; seeing the file means downloading it.

**What it records**
- **One piece, many places.** A piece of evidence (a file or a web address) is held once, in the company's evidence register (Audit ▸ Evidence), and can be linked to any number of records. It's the same piece everywhere, never a copy. Its details (name, type, classification, description, dates) are the piece's own, so changing them in one place changes them everywhere.
- **Evidence IDs.** Every piece gets an ID, **EVD-n**, numbered within its company (like CHC-n). Existing evidence is numbered in the order it was added.
- **One way to add evidence.** Everywhere Compass asks for evidence, an **Add evidence** button opens one large, nearly full-screen window with two tabs: **Add new evidence** and **Link existing evidence** (design below).
- **Classification is required when a person adds evidence** (Steve, 2026-11-20). It's a level on the data sensitivity scale (ADR 0124 §5), with no default. Evidence that arrives without a person handing it in (Evidence Collection, built-in check runs, the User Portal's incident report) comes in Not classified, as today. Existing Not classified evidence isn't forced. Once classified, a piece can change level but can't go back to Not classified.
- **See the evidence, not just its details** (Steve, 2026-11-20). Wherever a piece opens, the file previews beside its properties: PDF, images, text, CSV, and Word, Excel and PowerPoint from a PDF copy Compass makes in the background. The original is always what's downloaded and what goes in a pack; the copy is only for looking at. Web addresses open in a new tab rather than inside Compass. Uploaded files are never rendered as pages on Compass's own origin.
- **Removing vs archiving.** Taking a piece off one record only unlinks it there. Archiving it (with a reason, ADR 0122 §9 / COM-1738) archives it everywhere. A record that's finished (a done schedule entry, a closed incident, a finding closed, an audit ended) keeps what it was finished with. Archiving still shows there, as it does today.
- **Deleting for good.** An archived piece can be deleted for good (COM-1738) only when no finished record relies on it. Otherwise Compass says where it's used.
- **Schedule entries and their controls work both ways** (Steve, 2026-11-20). Evidence added to a schedule entry is also evidence on the entry's controls, and evidence on those controls can be picked when completing the entry.
- **Where the window isn't used:** places that keep a working document rather than the company's evidence keep their own upload. That means DDQs, standard and reviewed contracts, Trust Centre documents, data subject request letters and files, and a vendor's certificate (which is versioned on the certificate). Imports (CSV, findings, requests, threats, flowcharts) aren't evidence either.

**The window (Steve's design, 2026-11-20)**
- **Add new evidence:** a box to drag files into (or click to choose), and a box for a web address. Once added, the files and addresses are listed on the left. Clicking one shows its properties on the right to check and change, with the file previewed. The properties are file name, evidence type (required), classification (required), description and dates. Dates are filled in automatically and can be changed. Steve clicks through each file; there's no editing several at once. **Upload** adds them all once every file has its type and classification.
- **Link existing evidence:** the evidence register, with sortable columns (classification among them), filters, a search box and multi-select, and a preview of the highlighted row. Where the record has controls, it opens filtered to evidence on those controls, and the filter can be cleared (Steve, 2026-11-20).
