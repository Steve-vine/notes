Sprint "Vendor Departments". Found in the pre-UAT pass of COM-2134 on staging 0234a65f3 (24 Nov 2026). Screenshot: `~/compass-uat/sectbn9/COM-2134/07*`.

**Steve decided (24 Nov 2026): refresh the summary on Edit request.**

## The problem
When an approver asks for more information and the requester uses Edit request to change the department (or criticality, cost or any other field), the approver's review and the engagement show the new value. The summary under My requests still shows what the request said when it was first sent, because the summary is fixed at sending and an edit doesn't refresh it. This was true for every field before this sprint.

## What people see
- After Edit request is saved, the request's summary (My requests, and anywhere else the summary is shown) shows the request as it now stands: department, criticality, cost and every other field.
- What the request first said is kept in the activity log, as each edit already records the change.
- An amendment's "Changed X from A to B" lines also follow an edit to the amendment.

## Done when
- In E2E Test Company: send a new-vendor request with Finance, ask for information as the approver, change it to IT with Edit request. My requests shows "Department: IT", and the activity log still shows it was Finance.
- The same works for criticality and cost, and for an amendment's proposed change.

Probably independent (no migration expected; check whether the summary's stored shape changes the API).
