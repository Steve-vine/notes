Sprint "Vendor Departments". Found in the pre-UAT pass of COM-2134 on staging 0234a65f3 (24 Nov 2026). **Needs Steve's decision; not built.** Screenshot: `~/compass-uat/sectbn9/COM-2134/07*`.

## What happens today
When an approver asks for more information and the requester uses Edit request to change the department (or criticality, or cost), the approver's review and the engagement itself show the new value. The summary under My requests still shows what the request said when it was first sent. That summary is fixed at sending and an edit doesn't refresh it. This was already true for every field before this sprint; the department simply joined them.

## The choice
1. **Leave it.** The summary is a record of what was first asked for. The review and the engagement show the current value.
2. **Refresh the summary on Edit request,** so My requests always matches what the approver is deciding on. The first-sent values stay in the activity log.

If 2: the summary is rewritten on each Edit request for every field, not only the department. No migration is expected.
